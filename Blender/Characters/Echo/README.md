# Echo Blender Workspace

Canonical source file: `Echo_master.blend`

Production brief: `Docs/echo-blender-production-brief.md`

Echo follows Nova's first successful Blender → FBX → Unity visual-root round trip.

When beginning Echo, run:

`Blender/Tools/ns_character_source_setup.py -- --character Echo`

Save manually as `Echo_master.blend`.

The helper establishes the shared rig/socket/source-scene structure at Echo's
1.83 m target height. The approved Pursuit Protocol silhouette, collar/scarf,
headgear states, gauntlet tools, and staff/rifle must then be modeled by hand
from the approved visual references.
