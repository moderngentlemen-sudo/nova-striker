# Web Reference

The frozen gameplay reference is currently kept at the repository root:

`../nova-striker-v0.10-visual-completion-playable-preview.html`

Do not rewrite that file as part of the Unity migration. Use it to compare:

- movement acceleration and facing
- jump / double jump
- wall cling, slide, and jump
- charged multidirectional dash
- Powerslide
- omnidirectional aim
- charged fire
- melee and parry timing
- enemy reactions
- boss attack cadence
- co-op flow

Unity implementations should be evaluated against the reference by feel, not by copying browser-specific code architecture.
